常见问题

        
你可能想知道的。

      

      

        

          
Vornel 是什么？

          
Vornel 是一款跨平台的远程连接客户端，适用于 macOS 和 Windows，iOS 版正在开发中。一个应用里集成了 SSH 终端、SFTP 文件传输、RDP 远程桌面、VNC、Mosh、Telnet 和串口；主机、密钥和代码片段可以端到端加密后，同步到你自己的云存储。

        

        

          
Vornel 免费吗？

          
个人与非商业使用完全免费：没有付费版、没有广告，也不需要注册账号。源码以 PolyForm Noncommercial 1.0.0 许可公开在 GitHub 上，该许可不允许商业用途。

        

        

          
支持哪些系统？

          
macOS 13 及以上（Apple 芯片与 Intel 芯片各有安装包），以及 Windows 10 / 11（x64）。iPhone 与 iPad 版正在开发中。

        

        

          
加密同步怎样保护我的数据？

          
所有数据先在你的设备上加密：主密码经 Argon2id 派生出密钥，再用 XChaCha20-Poly1305 加密，然后才写进你选择的存储——AWS S3、Cloudflare R2、MinIO 等 S3 兼容存储，WebDAV，或者本地文件夹。Vornel 没有自己的服务器，主密码也从不离开你的设备，存储服务商只能看到密文。

        

        

          
能在多台服务器上同时执行同一条命令吗？

          
可以。把窗口分成最多四个窗格并打开“同步输入”，在任意一个窗格里敲的内容会同时发给所有窗格。常用的命令还可以存成代码片段，一键执行。

        

        

          
macOS 提示无法打开或无法验证开发者，怎么办？

          
macOS 版暂未经过苹果公证。macOS 15 及以上：先尝试打开一次，然后到“系统设置 → 隐私与安全性”，点“仍要打开”。macOS 13 / 14：在“应用程序”里右键点击 Vornel，选择“打开”。只需操作一次，之后就能正常打开，并会自动更新。
